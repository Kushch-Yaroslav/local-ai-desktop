# Local AI Desktop

**Development version: 0.4.0-development**

Local AI Desktop is an independent desktop AI agent application based on the open-source [Goose project](https://github.com/aaif-goose/goose). It uses Goose's Electron/React desktop, Rust agent runtime, providers, MCP extensions, Skills and session architecture, with Local AI Desktop branding and downstream development.

This project is independently maintained and is not affiliated with or endorsed by the Goose maintainers. Goose source is licensed under Apache-2.0; see [`LICENSE`](LICENSE), [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) and [`PROJECT_UPSTREAM.md`](PROJECT_UPSTREAM.md).

Product source, issues and future releases: https://github.com/Kushch-Yaroslav/local-ai-desktop

The v0.3.2.0 product history and tag remain available in this repository. Local model configuration, legacy data compatibility and advanced llama.cpp options are being prepared for later milestones.
