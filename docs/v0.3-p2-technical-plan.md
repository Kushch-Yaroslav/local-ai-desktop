## Confirmed before implementation

The external llama-server is 0.4.1-dev / d1d3c3396aa13a5f239109a822666c4870490ad5. React → Electron IPC → owned supervisor; Rust agent uses HTTP/SSE. Existing launcher already loads a configured projector, and attachments have native image routing. Browser screenshots currently return file paths and explicitly are not vision. Browser approval is per run; Page ownership is exclusive and origin/network boundaries remain mandatory.

Matching local server-common.cpp parses data image_url parts into multimodal buffers; server-context.cpp initializes mtmd and advertises multimodal capability. Image support is independent of MTP. mmproj initialization disables backend context shifting/cache reuse; application transcript compaction/checkpoint remains independent.

Read-only real probes (18 October 2026) loaded each model sequentially, never concurrently: Qwen3.8-27B Q4_K_M + qwen3.8-27b-mmproj.gguf (889 MiB), Qwen3.6-35B-A3B UD-Q4_K_M + mmproj-BF16.gguf (861 MiB), both with draft-mtp max2, context8192 Q8_0, CPU projector. MoE retained four CPU expert layers. A canvas contained only pixels, no shape DOM labels. Both returned exactly blue square, red triangle, yellow circle, HTTP200, 128 prompt tokens, 6/6 draft acceptance. Image round trip 1390.9 / 1540.2 ms; total GPU used 17659 / 21121 MiB; process RSS 2369.6 / 4241.8 MiB. These are small-image observations, not peak/max-context guarantees. Existing Qwen3.6 visionWithMtp=false is an unvalidated restriction that can now be removed for this tested configuration. Other architectures/backends remain unvalidated. No downloads or model changes.

## Architecture and sequence

1. **Hybrid integrated vision**: use the approved existing Playwright Page. Capture bounded viewport/region/element PNG with geometry, URL, timestamp and hash; send actual base64 bytes in a separate bounded HTTP request to the already loaded main model. Only image + fixed structured QA instruction, never whole task context or untrusted page instructions. No second model, browser or inference scheduler. Dedicated model swapping is unnecessary with these local models and would add lifecycle/OOM risks.
2. Persist independent global Browser Vision Off/Auto/On and Autonomous QA Off/On. Default Off for backward compatibility. Off blocks browser pixel transmission, not existing image attachments. Auto uses actual live multimodal capability or functional fallback. On requires capability and configured projector; explicit guarded reload if necessary, preserving MTP/history/checkpoint via the existing controller/rollback. Never Stop on selection. Projector placement remains the existing CPU/GPU preference (CPU default).
3. Add bounded browser QA: init instrumentation for uncaught/rejection errors, RAF/draw activity, delivered events and invalid canvas numeric arguments; real click/fill/keyboard/pointer/scroll assertions. Explicit expected state is distinct from event delivery and frame differences. Generic canvas smoke detects observed failures but cannot prove arbitrary application semantics. Persist per-action evidence with source fingerprint and honest Verified/Partially Verified/Failed/Blocked/Not Verified scopes. Screenshot/model budgets separate from Live Browser frames; duplicates reuse image result within a run, not an endless analysis loop.
4. Reuse Rust verification review, Task Memory and transcript: autonomous setting requires fresh QA before browser closeout, feeds concrete failures back for fix/retest, bounds reviews, and persists latest QA report through compaction/Pause/Resume. No new planning framework. Pause aborts expensive host vision request without treating it as final Stop; browser operations finish at safe boundaries.
5. Redesign only control panel into Model & Inference, Reasoning & Agent and Projects groups. Shared accessible reload modal with focus trapping/Escape/restoration; compact explanatory help, explicit live/after-response/reload affordances, pending/applied states and reduced-motion animations. Keep existing tokens/themes; support RU/EN and narrow windows. Compact QA section outside chat service-message history.
6. Verify with real Chromium instrumentation/negative fixtures, real Electron before/after screenshots + keyboard/focus/contrast/layout tests, and real Qwen image-only and detect/fix/retest scenarios. Run P0/P1 regressions, typecheck/lint/Rust/build. Record actual timings/resources; no mocked result is called real inference.

Limits: no continuous frame feed to LLM, no arbitrary page JS tool, no origin/approval bypass, no downloads, no user NEXUS mutation without authorization. Functional assertions and model visual opinions have separate provenance/confidence. Missing vision never becomes visually Verified.
