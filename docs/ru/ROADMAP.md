# Планы развития

[English](../en/ROADMAP.md) · [Русский](ROADMAP.md) · [Главная](../../README.ru.md)

Будущие направления без обещанных дат и обязательств. Реализованное описано в [Возможностях](FEATURES.md), условия выпуска — в [checklist](../releases/v0.2.0-checklist.md).

- **MCP:** внешние tool servers с явной авторизацией и границами жизненного цикла.
- **Долгосрочный опыт между задачами:** контролируемое сохранение знаний сверх существующих task-specific Task Memory и наблюдений проекта.
- **Diff/review UX:** удобная проверка реальных правок и восстанавливаемых версий файлов.
- **Координация нескольких агентов:** исследование принадлежности, общего состояния, разрешений и ресурсов до обещания параллельных агентов.
- **Расширение проверок:** воспроизводимое покрытие моделей/оборудования/дистрибутивов, больших историй, упаковки и обновления.
- **Mobile Chat Remote:** только исследовательская идея, не обещанная основная функция.
