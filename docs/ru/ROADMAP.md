# Планы развития

[English](../en/ROADMAP.md) · [Русский](ROADMAP.md) · [Главная](../../README.ru.md)

Это направления, которые проект может исследовать. Сроки не обещаны, планы могут измениться.

- Подключение внешних инструментов с понятным управлением разрешениями и жизненным циклом.
- Более удобная проверка изменений Agent и восстановление прежних версий файлов.
- Поиск безопасного способа делиться полезными знаниями проекта между задачами.
- Исследование взаимодействия нескольких агентов без путаницы в принадлежности задач и разрешениях.
- Расширение проверок совместимости Linux, моделей, оборудования и больших бесед.
- Изучение возможности пользоваться чатом Local AI Desktop с телефона.

Продолжение задач и память внутри отдельной задачи уже доступны. Это не общие знания, автоматически передаваемые между разными задачами. Актуальные возможности описаны в разделе [Возможности](FEATURES.md).
