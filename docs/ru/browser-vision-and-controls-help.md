# Browser Vision и подсказки панели

## Browser Vision до загрузки модели

Настройка `On` может быть сохранена, когда модель ещё не загружена. В этом состоянии UI показывает ожидание первой загрузки; доступность Vision не считается подтверждённой. Совместимость модели, локальные веса projector и фактическую поддержку изображений сервером проверяет путь загрузки модели. Несовместимая модель не запускается с ложным статусом Vision. Проектор не скачивается, модель не подменяется, значение MTP не меняется.

Для уже загруженной модели изменение `On` требует подтверждения и перезагрузки. Если сервер не подтвердит мультимодальный режим, операция завершается ошибкой без сообщения об активном Vision. Выбор режима сохраняется между перезапусками Electron.

## Проверки

`scripts/browser-vision-config-electron.test.mjs` проверяет через настоящий Electron UI, preload и IPC предварительную настройку до загрузки, переходы Off/Auto/On, сохранение после перезапуска, сохранение MTP и отказ при отсутствии projector у выбранной модели.

Реальный multimodal inference выполнен на локальной Qwen3.8-27B Q4_K_M с локальным projector. Снимок передавался модели как изображение, и ответ был помечен как проанализировавший изображение. Проверены Browser Vision On с MTP On, On с MTP Off, Auto с MTP Auto, On и Auto на уже загруженном runtime, а также Off. Замеры отдельных запросов составили около 3.14 с (MTP On + Vision On), 3.83 с (MTP Off + Vision On), 3.15 с (Auto + MTP Auto), 3.85–3.91 с для On/Auto на уже загруженной модели без MTP. Это проверка работоспособности, а не статистически значимый бенчмарк. В режиме Off изображение не анализировалось. Все процессы inference завершились.

## Подсказки

Единый `ControlHelp` показывает подсказки при наведении и фокусе клавиатурой. Подсказка привязана через `aria-describedby`, умеет закрываться по Escape, позиционируется внутри окна, остаётся доступной при наведении на неё и отключает анимацию при `prefers-reduced-motion`. В режиме Compact основные индикаторы имеют одну общую компактную подсказку.

Тексты объясняют назначение, ограничения во время работы и необходимость перезагрузки там, где это относится к настройке. Тексты панели и статусы Browser Vision/QA используют общий словарь RU/EN. У Browser QA без фактического анализа изображения остаётся честный результат `Partially verified`.

`scripts/control-tooltips-electron.test.mjs` проверяет все видимые controls панели: 17 элементов и 23 точки подсказок, включая английский и русский интерфейс, клавиатурный фокус, Escape, размещение у края окна, уменьшенное движение, узкое окно и сохранение mounted-состояния при сворачивании.
