## Модель и контекст

Укажите локальные GGUF и `llama-server` в настройках, выберите модель в панели. Открытие сохранённого чата само по себе не загружает и не перезапускает модель. Используйте явную загрузку и дождитесь ready.

Меню контекста содержит столбцы FP16 и Q8. Базовые размеры — 16K, 32K, 64K, 128K, 256K в пределах поддержки модели/backend; точные найденные значения добавляются без дублей. Поддерживаемый прежний выбор сохраняется. Стрелки перемещают выбор, Enter выбирает, Escape закрывает; список прокручивается.

| Индикатор | Значение |
| --- | --- |
| Нейтральный | Не оценено при подтверждённых сопоставимых условиях |
| Зелёный | В измеренном GPU-fit диапазоне этого типа KV при сопоставимых условиях |
| Бирюзовый | Точный найденный GPU-fit максимум этого типа KV |
| Жёлтый | Выше измеренного предела; может понадобиться больше памяти или загрузка завершится ошибкой |

Это статусы измерения, не гарантии. Результаты FP16 и Q8 не подтверждают друг друга. **Загрузить выбранную конфигурацию** позволяет использовать сохранённый или поддерживаемый ручной вариант без нового поиска. Изменение модели/runtime/памяти может вызвать предупреждение; запрошенные контекст и KV не заменяются молча. Ошибка backend доступна в раскрываемых деталях. Индикатор эффективного runtime описывает реально загруженную конфигурацию, а не будущий выбор.

### Поиск максимального контекста

**Найти максимальный контекст снова** выполняет ограниченные пробы модели под управлением launcher: перезапуски сервера, health checks, инференс, измерения памяти и восстановление прежней конфигурации. Это временно влияет на доступность модели; запускайте поиск осознанно, когда она не нужна активной задаче. Discovery даёт рекомендацию, не является обязательным этапом и не ищет исчерпывающий предел OOM.

Справка **Максимальный контекст** показывает краткое сравнение FP16/Q8, отдельные найденные максимумы, одну текущую сводку VRAM (всего/занято/свободно) и реальный предел модели/backend. Найденный максимум не является активным контекстом. При отсутствии телеметрии показано «неизвестно». Справка адаптируется к узким окнам и прокручивается по вертикали. Дополнительная диагностика — в мониторинге.

VRAM всего/занято/свободно — одна текущая сводка, не отдельное измерение каждого типа кэша. [Скриншоты контекста v0.2.0](../archive/releases/v0.2.0-validation-history.md#context-screenshots-and-discovery) иллюстрируют selector и справку; показанные значения не являются настройками по умолчанию.

Больший контекст требует больше памяти и может замедлять обработку запроса. CPU/RAM offload происходит только при поддерживаемой и настроенной схеме backend; исчерпание памяти может привести к ошибке загрузки. Точность KV отличается от квантования весов модели.

## Chat, Agent и проекты

**Chat** предназначен для беседы, **Agent** — для инструментов. Thinking/Reasoning зависят от модели; **Fast/Deep** — другая стратегия Agent. Начинайте с умеренной глубины. Долгие рассуждения сами по себе не подтверждают прогресс; смотрите действия и состояние runtime.

Выберите Project 1 и при необходимости Project 2; используйте `@` для ссылок внутри них. Отфильтрованный абсолютный путь, явно написанный вами, тоже может задать scope задачи (до четырёх явных корней). Он не становится выбранным UI-проектом и не получает подсказки `@`. Указывайте только те пути, которые намерены предоставить. Пути из ответа модели, репозитория или tool output не являются разрешением.

Явное продолжение восстанавливает сохранённую область задачи даже без выбранного сейчас проекта. Отсутствующая или перенаправленная папка требует явного корректного выбора; родительская папка не выдаётся автоматически. Scope файловых инструментов и writable mounts терминала различаются: проверенный cwd терминала доступен для записи, прочие места хоста обычно read-only или скрыты. Автопилот не снимает эти ограничения.

## Новая задача и продолжение

1. По умолчанию у ввода выбрана **Новая задача**. Независимые запросы получают разные планы и результаты даже в одном чате.
2. Для продолжения выберите недавнюю задачу у ввода или **Продолжить эту задачу** в истории. Заголовок и проект показывают владельца следующего сообщения.
3. **Новая задача** отменяет выбор. Само слово «продолжай» не определяет принадлежность.
4. Во время работы план/результаты видны у ввода; после окончания — в сворачиваемой карточке рядом с ответом/попыткой.

Историческая проверка описывает сохранённую попытку. Продолжение, Stop/resume и Regenerate создают новую попытку и не переписывают прежний снимок. При редактировании/регенерации ветки task-scoped попытки архивируются; обычное редактирование беседы может удалить последующие сообщения. Удаление беседы остаётся удалением, не гарантией архива. Старые планы уровня беседы читаются, но достоверно разделить их на прошлые логические задачи нельзя.

## Разрешения

- **Запрашивать подтверждение:** распознанное чтение проходит автоматически; правки и код требуют согласия. Проверьте команду/цель и разрешите один раз, в этой сессии либо откажите.
- **Абсолютный автопилот:** допустимые операции в scope задачи выполняются без повторных вопросов. Для включения режима не нужен выбранный UI-проект, но файловым/терминальным инструментам по-прежнему нужна установленная пользователем область задачи.

Selector у поля ввода меняет порядок подтверждений, не обязательную изоляцию или границы рабочего каталога.

Диалог разрешения показывает полную предлагаемую команду и целевой проект, варианты **Allow once** (один раз), **Always allow for this session** (в этой сессии) и **Deny** (отказать). Проверьте операцию перед согласием. [Скриншоты разрешений v0.2.0](../archive/releases/v0.2.0-validation-history.md#permission-screenshots-and-approval-flow) иллюстрируют эти элементы; показанная команда не является инструкцией к выполнению.

Этапа управления доверенными папками нет. «Разрешить один раз» разрешает текущий вызов. «Всегда разрешать в этой сессии» — ограниченный grant текущего чата и окна, сохраняющийся между заданиями и Pause/Resume, а не постоянное доверие папке и любым будущим командам. Grant привязан к операции, проекту, origin для preview и режиму безопасности; смена области или режима отзывает его. Grants можно просмотреть/отозвать в управлении разрешениями, в том числе между запусками. После перезапуска они не восстанавливаются. Смена режима влияет на следующие операции, не на уже завершённые.

Обязательные запреты нельзя снять подтверждением. Автопилот объясняет отказ вместо повторных запросов запрещённых действий. Для действия, допускающего ручную проверку, переключитесь в Ask; это всё равно не обходит filesystem, sandbox и защиту процессов.

## План, проверки и серверы

Задавайте конкретные результаты и подходящие проверки. **Реализовано** — утверждение агента; **Проверено** требует свежего runtime evidence подходящего вида и проекта. Тесты A не доказывают неизменность B. Без доверенного исходного состояния целостности такой пункт остаётся непроверенным. Настоящие правки требуют новых проверок; идентичные поддерживаемые записи — нет. Консервативная классификация сложного shell может потребовать простой scoped-команды, например `python3 -m unittest`.

Завершение плана само по себе не является проверкой. [Скриншот Agent v0.2.0](../archive/releases/v0.2.0-validation-history.md#agent-screenshot-reasoning-and-plan) показывает рассуждения, Mermaid, план и результаты вместе; числа описывают одну задачу, не приёмку выпуска.

Долгоживущий сервер запускается через managed terminal task, проверяется и останавливается по возвращённому handle. PID/порт из истории не является разрешением на очистку. Используйте managed stop вместо `kill`, `pkill`, `killall` и завершения по порту. Остановка задачи не даёт права остановить сервер модели.

## Stop, Pause и восстановление

**Stop** отменяет генерацию и её собственные операции; выполненные правки остаются. **Pause** кооперативна и достигает checkpoint на безопасной границе; текущая операция может успеть завершиться. После Stop, ошибки или перезапуска явно продолжите сохранённую задачу новой попыткой. Уточнения во время работы принадлежат текущей задаче и передаются на границе модельного хода.

Timeline показывает подозрение/подтверждение цикла, корректирующее указание, исключение повторов из контекста, попытки восстановления и их исход. Первое предупреждение сохраняет контекст. Устойчивый цикл может исключить доказуемый повтор из следующего запроса модели с сохранением всей видимой/постоянной истории. При небезопасной очистке или неудаче ограниченных повторов агент ставится на паузу. Кнопки показывают обработку до границы runtime; Stop остаётся доступен. **Продолжить без исправления** не отключает будущий детектор.

## Вложения, веб и Rich Responses

Прикладывайте документы/поддерживаемые изображения и проверяйте статус извлечения. Image Processing CPU/GPU выбирает только vision-путь. Сканам PDF нужен внешний OCR. **Web: Да / Нет** управляет веб-инструментами для чтения, а не всем трафиком терминала. Проверяйте источники и не доверяйте инструкциям веб-страниц.

Rich Responses поддерживает карточки, графики, таблицы, Mermaid и галереи. При ошибке диаграммы раскройте исходник/диагностику и при необходимости повторите рендер. Таблицы поддерживают копирование/CSV, графики и диаграммы — SVG. Поддержка рендера не гарантирует фактическую точность или способность каждой модели создавать все форматы.
