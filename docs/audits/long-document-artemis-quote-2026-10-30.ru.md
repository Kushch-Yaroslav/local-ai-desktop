# Artemis: quote mismatch и реальный тест чтения

Ветка `feature/optimize-long-document-reading`, продолжение `78e258d84ea4b330f367d430a48cc68fe74b94ef`.

**Результат:** блокировка на 0% устранена; настоящая Artemis обработала все 536 811 символов, сохранила 23 непрерывные заметки и сформировала ответ по всем 22 главам. **Полная смысловая достоверность пока не достигнута:** даже отдельный reviewer иногда сохраняет неподтверждённую причинную деталь. Нельзя считать задачу полностью закрытой по качеству пересказа.

## Причина и исправление

В пользовательском логе первый chunk `[0,24000)` завершился штатно: 56 965 мс, input 8504, output 1198, `stop`, reasoning=0. Исходная цитата генерировалась моделью в свободном поле `quote` (не обязательном `source_quote`). Старый рекурсивный `String.includes` отвергал **всю** заметку при одном несовпадении. Доставка текста и качество цитирования оказались ошибочно связаны с progress.

На старом коде ошибка воспроизведена настоящей Artemis: 62 734 мс, input 8501, output 1481, 0%. Из девяти цитат пять дословные, четыре сокращены с `...` или склеены из разных мест. Сохранённого raw ответа исходной пользовательской попытки нет; конкретные четыре цитаты относятся к воспроизведению. Ошибки offsets/декодирования не обнаружены.

Теперь приложение сохраняет собственный receipt: attachment/hash, точные UTF-16 `[start,end)`, hash chunk, исходный excerpt. Это подтверждает отправленный диапазон и завершённый ответ с содержательными заметками, **не понимание и не истинность всех утверждений**. Цитаты проверяются отдельно: exact, typography-normalized либо unverified. Unicode NFC, типографические кавычки/тире и пробелы/CRLF сопоставляются с offsets оригинала. Перефразирование не становится цитатой: сохраняется как непроверенное утверждение. Пустые заметки, ответ только с цитатой, malformed JSON, length и tool calls не подтверждают диапазон.

Реальные тесты выявили дополнительные дефекты: повторный запрос прочитанной книги мог получить только последний preview и сразу придумать сюжет; общий context fitting мог сжать всю память до 600 слов. Для явного чтения/пересказа по главам приложение теперь само передаёт сохранённую память через корректную tool-группу, не перечитывая диапазоны. В inference передаются все факты и observation IDs без повторения storage receipts; свежая память сохраняется целиком, если помещается с резервом 4096 токенов. Обычные разговоры не получают эту память автоматически.

Финал получает выбранные приложением начало и концовку. Перед показом ответ буферизуется и один раз сверяется с первичными excerpts и событиями глав. Reviewer редактирует блоки по ID приложения, без дословного копирования строк. При некорректных ID/JSON либо незавершённой проверке неподтверждённый текст не показывается, заметки сохраняются. Проверяется появление новых неподтверждённых сроков в заключительной главе; разрешена одна repair-попытка. Непрошенные тематические добавления после пересказа глав убираются; явно запрошенные интерпретации сохраняются. Это ограниченный локальный reviewer, не независимый доказатель истинности всей книги.

## Проверка качества и ограничения

Книга не загружалась целиком в контекст Codex: её программно читало приложение. Проверены структура, hashes, непрерывность, небольшие исходные фрагменты начала, середины и финала; изучены отдельные события заметок. Последний ответ содержит главы 1–22, корректно различает настоящее и воспоминания, в развязке Доктор жив, действует фикт, вещи возвращаются без боеприпасов, Бенито должен проводить Штыря до «Ростка». Исчез неверный финал о служении Штыря Доктору.

Однако в последней главе осталась фраза об участии «артефактов» в создании галлюцинации: первичный заключительный фрагмент этого не устанавливает. Другие промежуточные финалы ошибочно утверждали буквальное превращение, смешивали главы 11/12, а один reviewer придумал «две недели» вместо «двух месяцев». Проверка новых сроков покрыта регрессией; последняя реальная попытка не потребовала repair. **Reviewer остаётся вероятностным; совпавшая цитата и полный progress не доказывают смысловую точность. Все утверждения всех глав независимо не проверены.** Для старых очень объёмных заметок/меньшего окна также остаётся риск необходимости иерархического синтеза.
