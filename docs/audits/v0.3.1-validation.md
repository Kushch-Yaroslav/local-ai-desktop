# v0.3.1 integration validation

Both source branches are a single ancestry: `78e258d → d0d5137 → beb342f`. Integration starts from `beb342f`; nothing is cherry-picked twice.

The atomic-answer regression was introduced by intentional source-review buffering in `WebChatService`: normal SSE deltas were withheld, then `checked` was emitted as one token event. IPC forwards deltas correctly. The renderer's old queue also flushed synchronously on done, so splitting the finished string into events would not restore live streaming.

The patch explicitly marks already-reviewed, completed text. It keeps the complete answer and completion/persistence semantics immediately, carries a transient display timestamp across the saved-message replacement, and progressively renders that ready text for a bounded interval. Ordinary SSE, reasoning and tool events remain immediate. Reloaded history has no display hint; reduced-motion preference bypasses presentation. No unchecked draft is exposed before source review. This is presentation of ready text, not reconstructed inference.

Validation: TypeScript/typecheck/lint; long-document, launcher and reviewed-display regressions; actual isolated Electron display test (partial ready text → complete, ordinary deltas immediate, history immediate); Electron Chat context/telemetry (short, continuation, reasoning/tool/document paths, Stop, reopen); read-only Chat UI; renderer runtime status. Rust suite passed outside the restricted execution sandbox: 330 library tests, 96 agent-loop tests plus protocol/tool suites, one pre-existing ignored test. A language-sensitive test fixture was clarified to contain an unambiguously Russian phrase; product language detection was not changed.

GPU was occupied by the user's model; the guarded Artemis test correctly refused to allocate a second heavyweight model. The unchanged launcher/controller had previously passed actual Artemis 56K q8 KV-GPU recovery (see launcher audit). This integration additionally passed the real llama-server lifecycle using an isolated 9-MB synthetic CPU-only GGUF: offline/stale → ready, duplicate Load, restart, context/KV, alias switch, crash/recovery, startup failure/recovery. This is not an Artemis performance benchmark. Original user processes/configuration, GGUFs, conversations and book were not changed. The normal-startup test that requires no existing user instance was not forced; isolated packaged smoke tests cover startup instead.

RC1 package inspection passed: version/architecture/dependencies, static Rust binary, production JS graph (including underscore), packaged Electron module loading, controlled startup failure, six screenshots, and local documentation links. Final package is separately inspected before upload. No new demo video; v0.3.0 links/assets stay intact. Summary accuracy remains model-dependent; see bilingual release notes for case-specific measurements and limitations.
