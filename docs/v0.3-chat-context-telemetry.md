# Chat context monitoring

Branch: `fix/v0.3-chat-context-telemetry`, based on `b62b26d`.

Previously the renderer initialized telemetry only for Agent, whose Rust events
provide context statistics, per-turn usage and compaction counts. Ordinary Chat
sent final diagnostics and private segment records, but no equivalent live
panel updates. Internal document summaries and compaction requests were absent
from the panel. Unknown context was also rendered as `0 / limit` in its header.

Chat now reuses `ContextUsage` and the existing telemetry event. A per-run
observer covers both orchestration and internal inference calls. Exact tokenizer
measurements and provider usage update it before/during inference, when available.
No additional inference/tokenization requests or generation policy changes are
introduced. Agent retains its additive per-turn events; Chat sends absolute
snapshots, so repeated delivery cannot double-count usage.

- Context: measured prompt plus reported completion tokens of the latest
  inference request, including an internal document/compaction request.
- Input/output/run total: sums across every inference segment, summary and
  compaction call. A reduced current context never resets those sums.
- Model requests count inference calls; tool calls count unique actual calls,
  excluding progress/reading-status events. Compactions count completed passes.
- Duration uses run timestamps and the existing panel ticker. Snapshots survive
  Stop, conversation reopen and SQLite reopen. An unfinished recovered snapshot
  freezes at its last observation rather than running a new timer.
- Missing metrics remain `—`. When only part of cumulative usage is reported,
  the panel retains the measured subtotal as `measured + —`; the unknown part
  is never replaced with an estimate or zero. Backend completion usage includes
  reasoning/tool protocol. It is not a visible-text token estimate.

Validation: `npm run test:chat-context-telemetry` runs the build, lint, observer/
store/database tests and a production Electron/HTTP test. The HTTP provider is
controlled; this is not a new real-Qwen experiment. Cases cover live short
Chat, continuation, a 550K-character TXT, internal summaries, compaction,
Stop/reopen, unavailable usage/tokenizer and actual Rust Agent telemetry.
The compaction control records current context **1010** and cumulative usage
**1218**, demonstrating the distinct meanings. Existing 27 backend/security/
renderer suites and the 50K Electron streaming regression also pass.

Generation, file-tool permissions/behavior, Browser Workspace, runtime profiles
and the Rust Agent runtime are unchanged. Only observational usage callbacks,
Chat snapshot storage and the existing panel's data connection were added.
