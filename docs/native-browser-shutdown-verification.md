# Native Browser: ошибка при закрытии приложения

Ветка: `fix/v0.3-visual-region-feedback-pan`.

## Причина и исправление

При полном выходе Electron уничтожает дочерние Views. После этого свойство `shield.webContents` может стать `undefined`. Последующее отключение CDP запускало `detachPan`, который обращался к `shield.webContents.removeListener`. Это давало исключение из пользовательского скриншота.

Теперь ссылка на WebContents сохраняется при создании shield. Очистка снимает обработчики с сохранённого EventEmitter, даже если его нативная часть уже уничтожена. Завершение pan не обращается к уничтоженной поверхности. Общий Promise закрытия публикуется до начала очистки, поэтому повторные callbacks CDP используют одну операцию закрытия. Таймер регионов останавливается при закрытии Page. Глобального подавления ошибок в приложении нет.

## Проверка

`node scripts/native-browser-shutdown-electron.test.mjs` запускает настоящий Electron с отдельным временным runtime. Проверяются:

- Закрытие Native Page и повторный вызов `close` с тем же Promise.
- Уничтожение служебного WebContents перед очисткой.
- Уничтожение BrowserWindow.
- Отключение debugger/CDP.
- Уничтожение окна при активном обработчике pan.
- Полное завершение приложения с открытой Native Page.

На временной сборке с прежним обращением через `shield.webContents` полный выход воспроизвёл `TypeError: Cannot read properties of undefined (reading 'removeListener')` в `detachPan`. Исправленная сборка прошла все семь сценариев без uncaught exception и unhandled rejection. Исключения записываются только тестовым fixture; production-обработчики не заменяются.

Пользовательский runtime, история чатов, модели и проекты не изменялись. Проверка не использует LLM.
