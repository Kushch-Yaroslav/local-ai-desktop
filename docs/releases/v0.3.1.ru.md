# Local AI Desktop v0.3.1 — Стабильность и улучшения чтения документов

**Experimental Alpha · предварительный выпуск · Linux x86_64**

- Надёжнее загрузка моделей: исправлена редкая гонка launcher, из-за которой модель нельзя было загрузить из offline. Load восстанавливает отсутствующий supervisor; устаревшее состояние не считается активной моделью.
- Эффективнее чтение больших документов, сохранение прогресса и восстановление. Уменьшено повторное чтение, сохранённые заметки передаются полнее, усилена защита от полного пересказа частично прочитанного материала. Отличия в оформлении цитат больше не отбрасывают завершённый фрагмент целиком.
- Плавнее отображение после обработки документа. Обычные ответы продолжают поступать потоком. Готовый ответ после проверки по источнику сохраняется сразу и раскрывается постепенно; это отображение готового текста, не живая генерация. Сохранение не задерживается.

## Измерения и ограничения

Пользовательский тест Artemis 31B v1.2 на книге объёмом 536 811 символов: 36 мин 36 с, 26 запросов, 267 031 входных и 44 512 выходных токенов (311 543 суммарно), reported speed 22,6 ток/с, 0 сжатий. Показанный контекст — 27 119/57 344 токена; суммарный расход не равен заполнению одного окна. До исправлений этот случай занимал почти два часа: 111 запросов, остановка на 83,27%.

Отдельный технический прогон подтвердил полное покрытие: 23 последовательных диапазона, 22 главы. Обработка исходника заняла 27 мин 26,648 с без финальных проверок. Это конкретные измерения, не гарантия ускорения на всех моделях. В пересказах возможны неподтверждённые подробности, в том числе о причинных механизмах. Ограниченная проверка не устраняет галлюцинации полностью.

## Установка / обновление

Скачайте `local-ai-desktop_0.3.1_amd64.deb` и `SHA256SUMS` со [страницы GitHub](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/tag/v0.3.1), проверьте checksum и установите: `sudo apt install ./local-ai-desktop_0.3.1_amd64.deb`. Перед запуском новой сборки закройте старое приложение. Существующие модели и беседы сохраняются.
