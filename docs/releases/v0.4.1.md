# Local AI Desktop v0.4.1

A stability and usability update for the Goose-based desktop agent, with a focus on managed local GGUF inference and multi-agent sessions.

## Highlights

- **More reliable local multi-agent sessions.** Goose subagents can share one Desktop-managed llama.cpp server with parallel inference when the bundled runtime supports the required slot and KV behavior and available resources permit it.
- **Session-aware context management.** Goose receives the context reported by the running model. Subagents use their effective request budgets and the existing Goose compaction flow while the main chat retains its configured logical context.
- **Subagent visibility.** Child sessions and their saved histories are visible from the sidebar. Context Xray shows each subagent's logical token use and status alongside the main chat.
- **A reported real-world run.** A user reported successful completion of a three-subagent Qwen3.8-27B task with automatic compaction. This is an acceptance report, not a benchmark or a guarantee for other models and workloads.

## Improvements

- Added managed-runtime reporting for request context, slots, inference queue state, and useful failure details.
- Improved child-session lifecycle monitoring, history access, and context use display.
- Added sidebar actions to delete a saved chat or a project group and its child-session histories. Project directories and files are left untouched.
- Kept the existing GGUF context discovery and model profile controls, including KV-cache configuration and CPU/GPU offload settings.

## Fixes

- Fixed managed llama.cpp context capability propagation, including legacy managed Qwen profiles.
- Routed structured context and KV-capacity errors into Goose's existing reactive compaction and preserved more useful upstream error information.
- Prevented incomplete cleanup of a managed inference slot after request completion, cancellation, or failure from being treated as reusable capacity.
- Fixed Context Xray overflow and removed the redundant session selector while retaining the main-agent breakdown.
- Blocked deletion of active chat sessions and prevented project-group deletion from touching on-disk project files.

## Known limitations

- Parallelism depends on the bundled llama.cpp server's capabilities, selected slot/KV configuration, and available system memory. A shared unified KV pool is shared capacity; it is not a separate full-size physical cache for every agent.
- The desktop does not guarantee simultaneous use of the main chat's entire logical context and several full-size subagent contexts. Effective child budgets are constrained by the running server and scheduler.
- Clearing session KV may require prompt recomputation on later turns. No inference speedup is promised.
- GGUF behavior, context capacity, GPU offload, and stability vary by model, runtime, driver, and hardware. GGUF model weights are not included in the package.
- The reported Qwen3.8-27B run is not a broad compatibility test or performance benchmark.
