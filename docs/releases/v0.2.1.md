# Local AI Desktop v0.2.1

**Experimental Alpha · pre-release · release date October 16, 2026**

This small update improves the Agent's ability to check local web projects in a browser.

[Download the Linux amd64 package](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/download/v0.2.1/local-ai-desktop_0.2.1_amd64.deb) · [SHA-256 checksums](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/download/v0.2.1/SHA256SUMS) · [Русские примечания](v0.2.1.ru.md)

## Agent browser checks

The Agent could write a web page but could not always open it to check the result because local addresses were blocked by the ordinary web access rules.

The Agent can now use a separate browser tool to check a local web project or an approved local web address. It can open pages, follow links, inspect the page, report JavaScript and console errors, and save screenshots. This can reveal problems that are difficult to spot by reading source files alone.

Screenshots are saved as files. The model does not necessarily analyze their visual contents.

## Install and update

Download the amd64 `.deb` and checksum file from the [GitHub release page](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/tag/v0.2.1). Install or update on a supported Debian-based Linux system with:

```sh
sudo apt install ./local-ai-desktop_0.2.1_amd64.deb
```

Do not run the application as root. Agent terminal use requires Bubblewrap and enforcing AppArmor setup, followed by an administrator granting the desktop account access to the dedicated group. Follow [Getting started](../en/GETTING_STARTED.md) for setup and verification.

## Known issues

The Agent may finish the work and prepare a final answer while leaving some plan items open. An open item does not always mean the work failed, so check the actual result.

Recovery from repeated actions is not guaranteed. The app tries to help the Agent leave a loop, but it may continue similar actions or errors. If that happens, stop the run and clarify the task.

## Compatibility and limitations

This release targets Linux x86_64, with Ubuntu 24.04 as the primary tested environment. The app does not include `llama.cpp` or model weights. Local browser checks are limited to the selected project and explicitly approved local web addresses; ordinary public web tools do not gain access to local addresses.

This is Experimental Alpha software. AI results can be incorrect. Agent edits affect real files, so review changes and keep backups. For installation requirements, see [Getting started](../en/GETTING_STARTED.md).
