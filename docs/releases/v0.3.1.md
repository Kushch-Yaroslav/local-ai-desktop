# Local AI Desktop v0.3.1 — Stability & Document Reading Improvements

**Experimental Alpha · pre-release · Linux x86_64**

- More reliable model loading: fixed an occasional launcher ownership race that could prevent loading a model from offline. Explicit Load can recover a missing supervisor; stale state no longer counts as an active model.
- Improved long-document reading efficiency, recovery and progress tracking. Reduced redundant processing, preserved saved notes, and strengthened safeguards against complete summaries from partially read material. Quote formatting differences no longer discard an otherwise completed chunk.
- Smoother display after document processing. Ordinary model responses still stream directly. Answers held for source checking are saved immediately when complete and displayed progressively; this presentation step is not live inference and does not delay saving.

## Measurements and limitations

One user-reported Artemis 31B v1.2 run on a 536,811-character book completed in 36m36s: 26 model requests, 267,031 input and 44,512 output tokens (311,543 total), reported generation speed 22.6 tok/s, zero compactions. The displayed context was 27,119/57,344 tokens; aggregate usage is not context occupancy. Previously this case took almost two hours, used 111 requests and stopped at 83.27% coverage.

A separate technical run confirmed 23 contiguous ranges, 22 chapters and complete coverage; source processing alone took 27m26.648s, excluding final checks. These are case-specific measurements, not a universal speed guarantee. Model summaries can still contain unsupported details, including interpretations of causal mechanisms. Source checking is limited and does not eliminate hallucinations.

## Install / upgrade

Download `local-ai-desktop_0.3.1_amd64.deb` and `SHA256SUMS` from [GitHub](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/tag/v0.3.1), verify the checksum and install with `sudo apt install ./local-ai-desktop_0.3.1_amd64.deb`. Close the previous application before launching the updated build. Existing local models and conversations are retained.
