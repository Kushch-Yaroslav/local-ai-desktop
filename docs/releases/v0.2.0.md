# Local AI Desktop v0.2.0

**Experimental Alpha · pre-release · published October 15, 2026**

Compared with v0.1.0, this release makes coding tasks easier to continue, helps the Agent recover when it repeats itself, and gives you clearer control over model context and Agent permissions.

[Download the Linux amd64 package](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/download/v0.2.0/local-ai-desktop_0.2.0_amd64.deb) · [SHA-256 checksums](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/download/v0.2.0/SHA256SUMS) · [Русские примечания](v0.2.0.ru.md)

## Continue tasks across chats

Switch between chats and saved tasks, then return to work without losing its plan, progress or recorded verification results. The task menu lets you continue an existing task or start a new one. Continuing creates a new attempt, while earlier execution history stays available.

![Saved plan and verified deliverables with the Continue this task action and task selector](../img/releases/v0.2.0/continue.png)

## Recover from repeated actions

When the Agent starts repeating unproductive actions, Local AI Desktop gives it guidance and attempts a bounded recovery. If it cannot safely recover, the task pauses instead of repeating indefinitely. Recovery does not erase the original task history.

![Agent timeline showing its reasoning and task plan](../img/releases/v0.2.0/big-thinking2.png)

## Choose context settings with more information

The context controls now offer FP16 and Q8 KV-cache choices and save discovered context sizes separately for each cache type. You can see which settings loaded during discovery and choose a saved configuration without running discovery again. FP16 uses more memory; Q8 can use less with a possible precision tradeoff. Discovery results depend on the model, runtime and available memory, so they are not guarantees for every later run.

![Context selector with FP16 and Q8 choices](../img/releases/v0.2.0/context.png)

The context information panel summarizes the discovered values and current memory readings.

![Context information and measured memory summary](../img/releases/v0.2.0/context-info.png)

## More reliable Agent work

Plans, task notes, deliverables and verification results stay with their task as you move between chats. The Agent now gives clearer guidance when an edit fails or a previous check is no longer current. Reported verification is tied to the task and files that were checked; a successful check is not a guarantee that unrelated work is correct.

## Clearer permission choices

The app now presents two modes: **Ask for confirmation** and **Absolute Autopilot**. Ask requests approval for edits and commands. Autopilot allows routine actions within the current task and project scope without repeated prompts. Both modes retain the same mandatory terminal and filesystem boundaries.

![Choose Ask for confirmation or Absolute Autopilot](../img/releases/v0.2.0/select-autonomy.png)

![Example approval request for an Agent action](../img/releases/v0.2.0/ask.png)

## Other improvements

- Clearer model loading controls distinguish the selected context from the configuration currently active in the runtime.
- Agent status, long histories, terminal timing, Mermaid diagrams and error messages are easier to follow.
- File recovery and bounded web downloads provide clearer results and cancellation behavior.
- Linux package setup installs a dedicated enforcing AppArmor policy for Agent terminal isolation and requires an administrator to authorize each user account.

## Install and update

Download the amd64 `.deb` and checksum file from the [GitHub release page](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/tag/v0.2.0). Install on a supported Debian-based Linux system with:

```sh
sudo apt install ./local-ai-desktop_0.2.0_amd64.deb
```

Do not run the application as root. Agent terminal use requires Bubblewrap and enforcing AppArmor setup, followed by an administrator granting the desktop account access to the dedicated group. Follow [Getting started](../en/GETTING_STARTED.md) for required setup and verification.

## Compatibility and known limitations

This release targets Linux x86_64, with Ubuntu 24.04 as the primary tested environment. A clean installation and broad compatibility across distributions, hardware and drivers have not been independently verified. The app does not include `llama.cpp` or model weights.

Agent edits affect real files; review them and keep backups. Terminal isolation fails closed when its protections are unavailable, but it is not a privacy sandbox: readable host files may remain visible and network access is shared. Some development tools may not work inside the sandbox. Model fit depends on the GGUF, server build, context, cache precision, hardware and workload. Recovery from total memory exhaustion is not guaranteed.

For technical installation and security details, see the [Bubblewrap installation reference](../bwrap-installation-acceptance.md), [AppArmor security review](../apparmor-security-review.md) and [runtime protection reference](../runtime-self-protection.md).
