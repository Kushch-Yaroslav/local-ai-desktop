# Local AI Desktop v0.3.2.0 — Experimental Alpha

**Final Legacy Release · Pre-release · Linux x86_64**

The public release identifier and Git tag are `v0.3.2.0`. The Debian package and internal npm/Electron version use compatible SemVer `0.3.2`.

This release consolidates the current architecture's main llama.cpp runtime with opt-in dynamic MoE expert caching, tensor-aware CPU/GPU placement, mmap-aware RAM preflight, memory diagnostics and incremental HTTP/SSE handling. The release is experimental; these features have narrow validation coverage.

## Measured Qwen result

A historical paired experiment on an RTX 3090 with an experimental llama.cpp backend and 4K context allocation measured median decode of 29.07, 36.96, 46.82 and 56.25 tok/s at 0, 8, 12 and 16 GiB expert cache, respectively. The 16 GiB result was about 93.5% faster in that setup. It is not a general performance guarantee. The bundled runtime later loaded Qwen3-Coder-Next 80B with 16 GiB cache and Q8 GPU KV at 64K allocation for a short response; a fully populated 64K benchmark was not run.

Selected real MoE operations matched between dynamic cached CUDA and static CUDA in the tested fixtures. CPU and GPU arithmetic may still produce different logits and responses.

## Important limitations

- Experimental Alpha; not intended as a stable or production product.
- MoE support is validated on a narrow model and hardware set.
- Arbitrary layer placement depends on GGUF tensor names, architecture and supported backend buffers.
- Long Agent workflows and every tool sequence are not fully validated; semantic loops or excessive exploration may occur.
- Agent review can withhold final text until generation is complete.
- mmap pages may be reclaimed, reducing inference speed. Global swap-out is diagnostic and is not by itself a model stop trigger; the RAM reserve, cgroup and VRAM checks remain active.
- CPU/GPU outputs need not be identical.
- Some legacy regression scenarios remain failing; the complete repository test matrix is not green.
- No fully filled 64K context benchmark was performed.
- Validated packaging targets Linux x86_64, primarily Ubuntu 24.04 with the tested NVIDIA/CUDA configuration. Other platforms are not generally certified.

## Maintenance mode

v0.3.2.0 is the final planned functional release on the current architecture. Active development of this core is paused. The author plans to continue experiments on a new architecture based on a fork of another open-source project; no new app or upstream has been announced. This repository remains available as an experimental project and technical archive. Targeted fixes may be made, but regular updates are not promised.

## Install

Download the Linux amd64 `.deb` and `SHA256SUMS` from the GitHub Pre-release, verify the checksum, then install using `sudo apt install ./local-ai-desktop_0.3.2_amd64.deb`. The package does not include model weights. Review the [model acceleration and memory guide](../en/MODEL_ACCELERATION.md), [getting started](../en/GETTING_STARTED.md) and [user guide](../en/USER_GUIDE.md).
