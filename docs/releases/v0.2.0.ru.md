# Local AI Desktop v0.2.0

**Experimental Alpha · предварительный выпуск · опубликован 15 октября 2026 года**

По сравнению с v0.1.0 в этом выпуске проще продолжать задачи Agent в других чатах, восстанавливать работу после повторяющихся действий и выбирать контекст и разрешения.

[Скачать пакет Linux amd64](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/download/v0.2.0/local-ai-desktop_0.2.0_amd64.deb) · [Контрольные суммы SHA-256](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/download/v0.2.0/SHA256SUMS) · [English release notes](v0.2.0.md)

## Продолжение задач между чатами

Переключайтесь между чатами и сохранёнными задачами, а затем возвращайтесь к работе: план, прогресс и записанные результаты проверок останутся на месте. В меню можно продолжить существующую задачу или начать новую. Продолжение создаёт новую попытку, а история предыдущих запусков остаётся доступной.

![Сохранённый план и проверенные результаты, кнопка «Continue this task» и меню выбора задачи](../img/releases/v0.2.0/continue.png)

## Восстановление после повторяющихся действий

Если Agent снова выполняет бесполезные действия, Local AI Desktop подсказывает ему дальнейшие шаги и пытается восстановить работу с ограниченным числом попыток. Если безопасно продолжить нельзя, задача приостанавливается вместо бесконечного повтора. Исходная история задачи сохраняется.

![Временная шкала Agent с рассуждением и планом задачи](../img/releases/v0.2.0/big-thinking2.png)

## Более понятный выбор контекста

Настройки контекста теперь предлагают KV-кэш FP16 и Q8 и сохраняют найденные размеры контекста отдельно для каждого типа кэша. Можно увидеть, какие настройки загрузились при поиске, и выбрать сохранённый вариант без повторного поиска. FP16 требует больше памяти; Q8 может использовать меньше памяти с возможной потерей точности. Результат зависит от модели, runtime и доступной памяти и не гарантирует загрузку при любых следующих условиях.

![Выбор контекста с вариантами FP16 и Q8](../img/releases/v0.2.0/context.png)

Информационная панель показывает найденные значения и текущую оценку памяти.

![Информация о контексте и оценка использования памяти](../img/releases/v0.2.0/context-info.png)

## Более надёжная работа Agent

Планы, заметки, ожидаемые результаты и проверки остаются у своей задачи при переключении между чатами. Agent понятнее объясняет ошибки изменений и сообщает, когда прежняя проверка устарела. Результаты относятся к задаче и проверенным файлам; успешная проверка не гарантирует корректность остальной работы.

## Понятные варианты разрешений

Теперь в приложении два режима: **Запрашивать подтверждение** и **Абсолютный автопилот**. В первом Agent просит разрешение на изменения и команды. Автопилот выполняет обычные разрешённые действия в пределах проекта и задачи без повторных запросов. Оба режима сохраняют одинаковые обязательные ограничения файлового доступа и изоляции терминала.

## Другие улучшения

- При выборе контекста отдельно показаны выбранная настройка и конфигурация, которая сейчас используется runtime.
- Статус Agent, длинные истории, таймер терминала, диаграммы Mermaid и сообщения об ошибках стало проще читать.
- Восстановление файлов и ограниченные веб-загрузки яснее сообщают о результате и отмене.
- Установка Linux-пакета настраивает отдельную enforcing-policy AppArmor для терминала Agent; администратор должен явно разрешить доступ каждой учётной записи.

## Установка и обновление

Скачайте amd64 `.deb` и файл контрольных сумм со [страницы выпуска на GitHub](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/tag/v0.2.0). Установите пакет в поддерживаемой Debian-based Linux-системе:

```sh
sudo apt install ./local-ai-desktop_0.2.0_amd64.deb
```

Не запускайте приложение от root. Для терминала Agent нужны Bubblewrap и enforcing-профили AppArmor; после этого администратор должен добавить desktop-учётную запись в специальную группу. Обязательные шаги и проверки приведены в разделе [Начало работы](../ru/GETTING_STARTED.md).

## Совместимость и известные ограничения

Выпуск предназначен для Linux x86_64; основная проверенная среда — Ubuntu 24.04. Чистая установка и широкая совместимость дистрибутивов, оборудования и драйверов независимо не проверялись. Приложение не включает `llama.cpp` или веса модели.

Изменения Agent записываются в реальные файлы — проверяйте их и сохраняйте резервные копии. При недоступности защиты терминал откажется запускать команды, но это не изоляция конфиденциальности: читаемые файлы хоста могут быть видны, сеть общая. Некоторые инструменты разработки в изоляции работать не будут. Возможность загрузки модели зависит от GGUF, сборки сервера, контекста, точности кэша, оборудования и нагрузки. Восстановление после полного исчерпания памяти не гарантируется.

Технические подробности установки и защиты находятся в [справочнике по Bubblewrap](../bwrap-installation-acceptance.md), [обзоре AppArmor](../apparmor-security-review.md) и [описании защиты runtime](../runtime-self-protection.md). Исторические записи проверок сохранены в [архиве документации](../archive/README.md).
