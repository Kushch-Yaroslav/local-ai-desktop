# Local AI Desktop v0.2.1

**Experimental Alpha · предварительный выпуск · дата выпуска 16 октября 2026 года**

Это небольшое обновление помогает Agent проверять локальные веб-проекты в браузере.

[Скачать пакет Linux amd64](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/download/v0.2.1/local-ai-desktop_0.2.1_amd64.deb) · [Контрольные суммы SHA-256](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/download/v0.2.1/SHA256SUMS) · [English release notes](v0.2.1.md)

## Проверка в браузере

Раньше Agent мог написать веб-страницу, но не всегда мог открыть её для проверки: обычный веб-доступ блокировал локальные адреса.

Теперь Agent может использовать отдельный браузерный инструмент для проверки локального веб-проекта или разрешённого локального адреса. Он может открывать страницы, переходить по ссылкам, изучать страницу, сообщать об ошибках JavaScript и консоли и сохранять скриншоты. Так можно обнаружить проблемы, которые сложно заметить только при чтении исходного кода.

Скриншоты сохраняются как файлы. Модель не обязательно умеет анализировать их содержимое.

## Установка и обновление

Скачайте amd64 `.deb` и файл контрольных сумм со [страницы выпуска на GitHub](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases/tag/v0.2.1). Установите или обновите приложение в поддерживаемой Debian-based Linux-системе:

```sh
sudo apt install ./local-ai-desktop_0.2.1_amd64.deb
```

Не запускайте приложение от root. Для терминала Agent нужны Bubblewrap и enforcing-профили AppArmor; после этого администратор должен разрешить доступ учётной записи компьютера к специальной группе. Подробные инструкции приведены в разделе [Начало работы](../ru/GETTING_STARTED.md).

## Известные проблемы

Agent может выполнить работу и подготовить ответ, но оставить некоторые пункты плана незавершёнными. Это не всегда означает, что работа не выполнена, поэтому проверьте фактический результат.

Восстановление после повторяющихся действий не гарантировано. Приложение пытается помочь Agent выйти из цикла, но он может продолжить похожие действия или повторить ошибку. В таком случае остановите выполнение и уточните задачу.

## Совместимость и ограничения

Выпуск предназначен для Linux x86_64; основная проверенная среда — Ubuntu 24.04. Приложение не включает `llama.cpp` или веса модели. Проверки в браузере ограничены выбранным проектом и явно разрешёнными локальными адресами; обычные веб-инструменты не получают доступ к локальным адресам.

Это Experimental Alpha. Результаты AI могут быть неверными. Agent изменяет реальные файлы — проверяйте изменения и сохраняйте резервные копии. Требования к установке описаны в разделе [Начало работы](../ru/GETTING_STARTED.md).
