# Local AI Desktop v0.3.2.0 — Experimental Alpha

**Заключительный релиз текущей архитектуры · предварительный выпуск · Linux x86_64**

Публичный номер и Git-тег — `v0.3.2.0`. Debian-пакет и внутренняя npm/Electron-версия используют совместимый SemVer `0.3.2`.

Релиз объединяет текущий основной llama.cpp runtime, экспериментальный динамический MoE-кэш, размещение тензоров CPU/GPU, RAM preflight для mmap, диагностику памяти и постепенный разбор HTTP/SSE. Поддержка этих функций проверена ограниченно.

## Измерения Qwen

Исторический парный тест на RTX 3090 с экспериментальным llama.cpp и allocation контекста 4K измерил медиану decode 29,07 / 36,96 / 46,82 / 56,25 tok/s при кэше экспертов 0 / 8 / 12 / 16 GiB. Результат 16 GiB был примерно на 93,5% быстрее в этой конфигурации, но не гарантирует такого ускорения в других условиях. Позднее встроенный runtime загрузил Qwen3-Coder-Next 80B с кэшем 16 GiB и Q8 GPU KV при allocation 64K и завершил короткий ответ. Полный benchmark с заполненным контекстом 64K не проводился.

Выбранные реальные MoE-операции совпали в проверенных fixtures между dynamic cache CUDA и static CUDA. Численные различия CPU/GPU могут менять logits и ответы.

## Важные ограничения

- Experimental Alpha; это не стабильный и не production-продукт.
- MoE проверен на ограниченном наборе моделей и оборудования.
- Произвольное размещение слоёв зависит от имён тензоров GGUF, архитектуры и буферов backend.
- Длинные Agent workflow и все последовательности инструментов проверены не полностью; возможны циклы и избыточное исследование.
- Проверка Agent может отложить показ финального текста до окончания генерации.
- mmap-страницы могут вытесняться и замедлять модель. Общесистемный swap-out диагностируется и сам по себе не останавливает модель; RAM reserve, cgroup и VRAM проверки сохранены.
- Ответы CPU и GPU не обязаны совпадать побайтово.
- Некоторые старые регрессионные сценарии остаются не пройдены; весь набор тестов репозитория не зелёный.
- Benchmark с заполненным контекстом 64K отсутствует.
- Пакет проверялся для Linux x86_64, преимущественно Ubuntu 24.04 с тестовой конфигурацией NVIDIA/CUDA. Другие платформы не сертифицированы.

## Режим сопровождения

v0.3.2.0 — последний запланированный функциональный релиз на текущей архитектуре. Активная разработка этого ядра приостановлена. Автор планирует продолжить эксперименты на новой архитектурной основе, используя форк другого open-source проекта; новое приложение и upstream пока не объявлены. Репозиторий остаётся доступным как экспериментальный проект и технический архив. Возможны точечные исправления, регулярные обновления не обещаются.

## Установка

Скачайте Linux amd64 `.deb` и `SHA256SUMS` со страницы предварительного релиза GitHub, проверьте checksum и установите `sudo apt install ./local-ai-desktop_0.3.2_amd64.deb`. Веса моделей в пакет не включены. См. [руководство по ускорению моделей и памяти](../ru/MODEL_ACCELERATION.md), [начало работы](../ru/GETTING_STARTED.md) и [руководство пользователя](../ru/USER_GUIDE.md).
