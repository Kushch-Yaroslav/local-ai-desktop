# Local AI Desktop v0.3.0

**Experimental Alpha · локальная сборка · 28 октября 2026 года**

Это локально подготовленная версия. Пакет не загружен на GitHub или другие сайты распространения.

## Основные изменения после v0.2.1

- **Agent Runtime V2:** постоянное состояние задач, продолжение прерванной работы, ограниченное восстановление и улучшенные сценарии проверки.
- **Browser Workspace:** native и live preview, изменяемые и пользовательские viewport, визуальные области, Browser QA и журнал проверки.
- **Model Runtime:** улучшенное обнаружение отдельных GGUF и восстановление cold start, настройки контекста, профили моделей, диагностика возможностей MTP и Vision.
- **Инструменты Chat только для чтения:** обычный чат может читать поддерживаемые вложения без выбранного проекта. Полный текст документов сохраняется между сообщениями и перезапусками; большие файлы обрабатываются постепенно с сохранением offsets, конспектов и состояния compaction. Agent может читать те же вложения отдельным инструментом.
- **Чтение проекта и Browser Workspace в Chat:** при выбранном проекте чат может просматривать и искать файлы, читать ограниченные фрагменты исходников, исследовать проверенные метаданные Visual Region и читать уже открытую разрешённую страницу Browser Workspace. Описание Canvas обозначается как вывод по исходникам, если пиксели действительно не передавались модели с поддержкой Vision. Изменение файлов, terminal-команды и действия в браузере остаются возможностями Agent.
- **Длинный Chat и мониторинг контекста:** ответ может состоять из нескольких inference-сегментов с общим бюджетом до 50K выходных токенов. Телеметрия Chat показывает измеренный контекст, токены, запросы модели, вызовы инструментов, длительность и compaction.
- **Обнаружение моделей в Linux:** после монтирования диска через файловый менеджер приложение обновляет список доступных GGUF.

## Установка локального пакета

Из корня репозитория установите локальный Debian-пакет amd64:

```sh
sudo apt install ./release/local-ai-desktop_0.3.0_amd64.deb
```

Пакет включает приложение и Rust Agent runtime, но не `llama.cpp`, веса GGUF и projectors. Не запускайте приложение от `root`. Для терминала Agent нужны настройка Bubblewrap и enforcing-профили AppArmor с разрешением администратора; см. [Начало работы](../ru/GETTING_STARTED.md).

## Известные ограничения

- Это **Experimental Alpha**. 50K — бюджет оркестрации, а не обещание, что модель выдаст такой объём. Естественный `stop` может завершить ответ раньше; длинный результат нужно проверить на полноту, повторы и соответствие запросу.
- Поддержка моделей и скорость зависят от GGUF, сборки `llama.cpp`, доступной памяти, GPU, контекста и размещения projector. Загрузка модели и производительность не гарантированы на каждом компьютере.
- Приложение не загружает модели. Перед доступом к GGUF на съёмном диске его нужно смонтировать.
- Agent может менять файлы проекта. Ограничения терминала обязательны, но доступные приложению файлы хоста и сеть не являются границей приватности.
- Пакет проверен на текущей Ubuntu. Поведение при чистой установке и широкая матрица дистрибутивов Linux, GPU и драйверов независимо не проверялись.
