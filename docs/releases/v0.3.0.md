# Local AI Desktop v0.3.0

**Experimental Alpha · local release · 28 October 2026**

This is a locally prepared release. It has not been uploaded to GitHub or another distribution service.

## Highlights since v0.2.1

- **Agent Runtime V2:** persistent task state, resumable work, bounded recovery and stronger verification workflows.
- **Browser Workspace:** native and live previews, resizable and custom viewports, visual regions, Browser QA and a verification ledger.
- **Model runtime:** improved per-model GGUF discovery and cold-start recovery, context controls, model profiles, MTP and Vision capability diagnostics.
- **Read-only Chat tools:** Chat can inspect supported attachments without a project. Full document sources remain available across messages and restarts; large files are read progressively with saved offsets, notes and compaction recovery. Agent can access the same conversation attachments through its read-only tool.
- **Read-only project/browser Chat:** With a selected project, Chat can list and search its files, read bounded source ranges, inspect validated Visual Region metadata and read the already-open approved Browser Workspace. Canvas descriptions are identified as source-based inference unless pixel input actually reached a vision-capable model. Project writes, terminal commands and browser actions remain Agent capabilities.
- **Canvas without source mapping:** Empty region anchors, source hints or pixel input do not prevent Chat from investigating the selected project's page and rendering code. Read access is already authorized; preview URL paths are only relative file lookup candidates, and source evidence does not establish the exact selected pixels.
- **Long Chat and context monitor:** length-limited answers can use multiple inference segments within a cumulative budget of up to 50K output tokens. Chat telemetry shows measured context, token usage, model requests, tool calls, elapsed time and compactions.
- **Linux model discovery:** the application refreshes GGUF availability after you mount a model drive in the file manager.

## Install this local package

From the repository root, install the local amd64 Debian package:

```sh
sudo apt install ./release/local-ai-desktop_0.3.0_amd64.deb
```

The package includes the desktop application and Rust Agent runtime. It does not include `llama.cpp`, GGUF weights or model projectors. Never launch the desktop application as root. Agent terminal use requires administrator-authorized Bubblewrap and enforcing AppArmor setup; see [Getting started](../en/GETTING_STARTED.md).

## Known limitations

- This is an **Experimental Alpha**. The 50K figure is an orchestration budget, not a promise that a model will generate that much. A natural `stop` may end an answer earlier; review long output for coverage, repetition and completeness.
- Supported models and performance depend on their GGUF files, `llama.cpp` build, available memory, GPU, context and projector placement. Model loading and throughput are not guaranteed on every machine.
- Models are not downloaded by the application. Removable storage must be mounted before its GGUF files are available.
- Agent can change project files. Its terminal restrictions are enforced, but readable host files and network access are not a privacy boundary.
- The package is checked on the current Ubuntu system. Clean-install behavior and a broad Linux distribution, GPU and driver matrix have not been independently verified.
