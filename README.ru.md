# Local AI Desktop

[English](README.md) · [Русский](README.ru.md)

Экспериментальное настольное приложение для Linux: локальный чат с LLM и задачи по разработке. Инференс GGUF выполняет внешний сервер llama.cpp; интерфейс использует Electron, Agent Runtime V2 — Rust.

[Опубликованные выпуски](https://github.com/Kushch-Yaroslav/local-ai-desktop/releases) · [Установка](docs/ru/GETTING_STARTED.md) · [Руководство](docs/ru/USER_GUIDE.md) · [История выпусков](CHANGELOG.md)

Документация репозитория описывает текущее дерево исходников. Опубликованные пакеты могут содержать более ранний набор возможностей; см. [статус выпусков и примечания](docs/README.md#release-status).

## Возможности

- Локальные Chat и Agent для работы с проектами: потоковые ответы, вложения, необязательные веб-инструменты для чтения и Rich Responses.
- Два проекта и ссылки на файлы через `@`; планы, Task Memory, результаты и исторические снимки проверки принадлежат конкретной задаче.
- Явное продолжение задачи, Stop/возобновление и ограниченное восстановление после циклов с сохранением исходной истории выполнения.
- **Запрашивать подтверждение** и **Абсолютный автопилот** с обязательными ограничениями файлового доступа и защиты процессов.
- Изолированный терминал и управляемые серверы разработки; проверка по свежим доказательствам в области задачи.
- Выбор контекста FP16/Q8 с учётом модели, сохранённые результаты поиска максимума и телеметрия runtime.

Подробности: [Возможности](docs/ru/FEATURES.md), [Наблюдения по моделям](docs/ru/MODELS.md), [Планы развития](docs/ru/ROADMAP.md).

## Установка и безопасность

Текущая платформа — Linux x86_64; основная проверенная среда — Ubuntu 24.04. Нужны совместимый `llama-server` и локальные веса GGUF; они не включены в пакет. Для терминала Agent также нужны средства изоляции, описанные в [Начале работы](docs/ru/GETTING_STARTED.md).

Автопилот не предоставляет неограниченный доступ к хосту. Изоляция PID, seccomp и ограничения файловой системы сохраняются; проверенная конфигурация Ubuntu использует отдельные enforcing-профили AppArmor. Записи в проект меняют реальные файлы, чтение хоста не скрыто полностью, сеть общая. См. [границы защиты](docs/ru/FEATURES.md#security-boundaries). Делайте резервные копии и проверяйте результат.
